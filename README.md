# FIELD FORM — Farm-to-Table Organic Directory

A complete responsive static HTML website for an organic farm, bakery and confectionery directory.

## Pages
- Home
- Directory
- Our Story
- How It Works
- Contact

## Design
- Normal readable typography and section heights
- Two-line page H1s
- Editorial organic-food visual language
- Animated hero typography, orbit rings, floating cards, reveal effects, marquee and hover motion
- Responsive navigation and mobile layout
- Reduced-motion support
- Modern SVG logo and favicon

## Notes
All content and contact details are demo/fictitious. Forms are front-end demo interactions.
